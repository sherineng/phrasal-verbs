# Фразовые глаголы — тренажёр

Статический сайт (чистые HTML/CSS/JS, без сборки и зависимостей) по списку фразовых глаголов из файла «ВСЕ_фразовые_глаголы.pdf».

**Что внутри**

| Раздел | Что делает |
| --- | --- |
| 🔎 Поиск | Ищет по-английски и по-русски: по глаголу, значению и по примерам. Подсветка совпадений, фильтр по базовому глаголу, избранное ★ |
| 🃏 Карточки | Переворот по клику или Пробелу, «знаю / не знаю», звёздочки, перемешивание. Переключатель «Вводить ответ» — ответ на английском или русском |
| 🧠 Заучивание | Раунды по 7 карточек: сначала выбор ответа, затем письменный |
| ✍️ В контексте | Предложения из базы с пропуском: вписать фразовый глагол в нужной грамматической форме (время, лицо, вспомогательные глаголы). Подсказки, «Глагол верный, но форма другая», раунды по 10 |
| 📝 Тест | Выбор ответа, верно/неверно, письменный ответ, сопоставление. Разбор ошибок и «Повторить ошибки» |
| 🧩 Подбор | Найти пары «глагол — значение» на время, рекорд сохраняется |

Кнопка 📚 вверху задаёт набор: язык вопроса (EN / RU / вперемешку), «все / избранные / невыученные / с ошибками» и выбор базовых глаголов (break, come, get…).
Прогресс и избранное хранятся в браузере (`localStorage`).

В базе: 208 фразовых глаголов, 450 значений, 959 примеров с переводом. К каждому значению есть пример из исходного файла и дополнительный. Дополнительные примеры в поиске помечены «доп.», примеры из ФИПИ — «ФИПИ».

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы этой папки (корень репозитория = папка с `index.html`).
2. В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Локально можно просто открыть `index.html` в браузере или запустить `python3 -m http.server`.

## Как править данные

Исходники лежат в `data/*.txt`. Формат простой:

```
= back off                                   ← глагол (после | можно задать отображаемое имя и синонимы)
- отступить, отойти подальше (от опасности)  ← значение
~ to move back or away from someone or something, especially to avoid danger   ← английская дефиниция (обязательна)
> When the bear stood up, the hikers backed off. | Когда медведь встал, туристы отступили.   ← пример из файла
+ The crowd backed off when the police arrived. | Толпа отошла, когда приехала полиция.      ← дополнительный пример
```

- `- [паттерн] значение` — паттерн (например `[break up (with smb)]`) показывается над значением.
- `>f` — пример из ФИПИ.
- `~` — английская дефиниция значения. Формулировки свои, в стиле learner's dictionary (не копия Cambridge/Oxford); рядом с каждым глаголом есть ссылки на статьи этих словарей.
- Первое слово из `= name` определяет базовый глагол для фильтра.

После правок пересоберите `js/data.js`:

```bash
python3 tools/build_data.py
```

Скрипт проверяет, что у каждого значения есть пример и перевод, и сообщает об ошибках.

## Проверка письменных ответов

- Английский: регистр, `smb/smth` и скобки не важны, одна опечатка прощается. Другой глагол с тем же значением (например, `turn off` вместо `switch off`) засчитывается с пометкой.
- Русский: подходит любой синоним из значения («расстаться», «расстались»). Если ответ засчитан неверно, есть кнопка «Я был прав».
